# QUESTLOG

## World 1: The Tutorial Tavern (Week 1)

### Quest 1: The Sync Spell (5 min, 20 XP)
Goal: prove your first commit reached GitHub.
- [x] github.com/nT-pen/js-learning shows your new README sentence and 2 commits
Won when: you can see both on the page.

### Quest 2: Scroll of Welcome (25 min, 30 XP)
Goal: learn how The Odin Project (TOP) works.
- [ ] TOP Foundations: the Introduction lessons, in the order on their site
Won when: you can say in one sentence what TOP expects from you.

### Quest 3: Map of the Realm (35 min, 40 XP)
Goal: understand what the web actually is.
- [ ] TOP Prerequisites: Computer Basics and How Does the Web Work?
Won when: you can explain what happens when you type a website address, in your own words.

### Quest 4: Terminal Treasure Hunt (40 min, 50 XP)
Goal: move around your computer using only typed commands.
- [ ] TOP: Command Line Basics
- [ ] In the VS Code terminal, without clicking: find your current folder, list its files, make a folder called `practice`
Won when: `practice` exists inside `js-learning` and you made it by typing.

### Quest 5: The Git Scribe (20 min, 30 XP)
Goal: make your Git knowledge solid.
- [ ] Skim TOP's Git setup lessons (you've done the hands-on part already)
Won when: you can explain staging vs committing without peeking.

### Side Quest: The Arcade Door (10 min, 20 XP)
- [ ] On CodinGame, set JavaScript as your language and peek at a Clash of Code lobby. Don't play yet.

### 🐉 BOSS FIGHT: The README Dragon (45 min, 100 XP)
Goal: run the full workflow on a brand-new project, on your own.
- [ ] Create a new public GitHub repo called `hello-quest` with a README
- [ ] Clone it into VS Code
- [ ] Add 3 short sections to the README (who you are, why you're learning, your goal)
- [ ] Make at least 3 commits, each with a clear message
- [ ] Push it to GitHub
Won when: the repo is public, shows 3+ commits, and the README looks like a real front page.
